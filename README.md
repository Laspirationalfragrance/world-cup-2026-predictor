# ⚽ 2026 世界杯 AI 预测 (World Cup 2026 Predictor)

基于 Elo 评级、FIFA 积分、近期状态、球队身价和阵容评分的机器学习模型，对 2026 世界杯 72 场小组赛进行概率预测。包含 20,000 次蒙特卡洛模拟的完整赛事推演。

## 🚀 在线查看

**手机扫码或打开**: `https://<你的用户名>.github.io/<仓库名>/`

## 📊 功能

- 📅 **日期选择器** — 按天查看比赛预测，支持左右滑动切换日期
- 📈 **胜/平/负概率** — 每场比赛的三元概率 + 可视化概率条
- 🏟️ **场地信息** — 球场、城市、主客场/中立标注
- 🏆 **夺冠概率 TOP 8** — 查看全部比赛时展示冠军热门
- 📋 **小组晋级形势** — 选择某天时展示当天比赛小组的晋级概率表
- 🔥 **爆冷风险标记** — 高亮标注接近的比赛（胜率差 < 10%）
- 🎯 **预测比分 & 置信度** — 高/中/低三档置信度，颜色区分
- 📱 **移动端优化** — 专为手机浏览设计，支持 PWA

## 🛠 本地运行

```bash
# 启动本地服务器
cd docs
python -m http.server 8080
# 或
npx serve docs
```

浏览器打开 `http://localhost:8080`

## 📁 项目结构

```

│   ├── index.html      # 主页面
│   └── data.js         # 嵌入的预测数据
├── scripts/            # 模型训练和预测脚本
├── data/               # 原始数据和特征工程

```

## ⚠️ 免责声明

所有预测基于统计模型。足球比赛受临场状态、裁判、红牌、偶然性影响极大。概率 ≠ 确定性。本页面仅供娱乐参考，不构成投注建议。
